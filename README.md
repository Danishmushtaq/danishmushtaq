## 📊 Featured Project

### 🛒 E-Commerce Delivery Prediction

An end-to-end machine-learning project analysing Brazilian e-commerce delivery performance.

**What I worked on:**

- Data cleaning and preparation
- Exploratory data analysis
- Feature engineering
- Customer and order-level analysis
- Random Forest classification
- Logistic Regression
- Imbalanced classification
- Model comparison
- Probability threshold optimisation
- Business recommendations

**Key result:**

The final Random Forest approach using customer-state information and a 0.30 classification threshold achieved:

- **87% Accuracy**
- **22% Late Precision**
- **40% Late Recall**
- **28% Late F1-score**

The project demonstrates why accuracy alone can be misleading when predicting a minority class.
